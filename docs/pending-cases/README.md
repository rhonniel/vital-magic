# Casos pendientes

Registro ligero de los casos que el propietario pidio conservar en la revision de testing del 2026-09-10.
La fuente de decisiones es la solicitud revisada de ejecucion; no constituye una nueva auditoria.

- [testing.md](testing.md): pruebas aplazadas explicitamente. IDs `TEST-NNN`.
- [decisions.md](decisions.md): contratos que requieren una decision humana. IDs `DEC-NNN`.

Conservar los IDs al actualizar o resolver un caso. Una entrada pendiente no autoriza su implementacion.
No registrar recomendaciones rechazadas ni ampliar el alcance por cobertura.
